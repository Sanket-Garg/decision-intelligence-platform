
# Decision Intelligence Platform

A machine learning platform for credit risk scoring and retail sales forecasting.

## Project Goals

- **Credit Risk Scoring:** Predict the risk of serious borrower delinquency.
- **Retail Sales Forecasting:** Forecast future retail sales using historical data.

## Project Structure

- `src/` — Application and machine learning code.
- `data/` — Datasets and prepared data.
- `tests/` — Automated tests.

## Project Status

Currently in the initial setup and learning phase.
